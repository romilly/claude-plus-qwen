How MENACE Works

MENACE (Matchbox Elastic Net for Adaptive Computation) is a machine learning device designed by Donald Michie in 1961.

Each matchbox represents a game state:

  • Each matchbox has colored beads representing possible moves
  • When MENACE wins, it adds more beads of that color to the matchbox
  • When MENACE loses, it removes beads from the matchbox
  • When it's a draw, it slightly modifies the bead counts
  • The machine learns through experience and improves over time
